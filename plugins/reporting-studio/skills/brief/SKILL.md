# Brief

1. Start with the audience, decision, and period. Lead with the most consequential observation in plain language.
2. Support each conclusion with a specific metric or source. Include units, denominators, and cohort labels where they affect interpretation.
3. Distinguish the observation, the interpretation, and the proposed action. For each action, state what should happen and what evidence would establish progress.
4. Use a small comparison table when it improves scanning. State missing measurements and incomplete checks explicitly. Verify the brief against the source or shared metrics before submission.
