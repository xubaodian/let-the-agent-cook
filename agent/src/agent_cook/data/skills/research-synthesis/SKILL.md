# Research synthesis

## Language and storyline

Write in the requested language. Keep the language of the existing deliverable for revisions by default, and match the user's language for new work. Start with a direct answer to the reader's question. Put the strongest relevant evidence next, then explain what it means and what remains uncertain. Use everyday words and define source terms the reader needs to understand.

## Gather and verify evidence

1. Turn the request into a short list of facts to establish. Search by topic and locale, then narrow by date, document type, or audience where the source supports it.
2. For each fact, capture the source ID, title, version or date, and the supporting excerpt. Prefer current applicable material. Record an older version when the change itself matters.
3. Resolve conflicts by scope and version. Record remaining uncertainty with the exact fact or rule still needed.
4. Save reusable evidence as JSON or a short Markdown file. Keep claims tied to their references, especially deadlines, eligibility, numeric limits, and benchmark definitions.
5. Write a concise synthesis grounded in the evidence. Check each action, number, or requirement against its source before reusing it in another artifact.
