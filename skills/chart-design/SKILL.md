# Chart design

1. State the one question the chart answers. Use a bar for category comparison, a line for an ordered time series, or a scatter plot for a relationship between two measures. For a handful of exact values, consider a table.
2. Build the series from the verified data file. Keep counts, currencies, and percentages identifiable. Use aligned periods and compatible units for series that share an axis. Show missing observations as gaps or label them unavailable.
3. Carry the measure, unit, period, and benchmark cohort into the titles or labels. Use a direct label or a small legend when series need to be distinguished. Keep each category's color consistent across related charts.
4. Render at the intended size. Check that labels fit, the order and scale support the intended comparison, and labels match the data. Use native charts in editable deliverables when the format supports them.
