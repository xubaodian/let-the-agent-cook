# Locale review

1. Identify the user-requested locale and any existing terminology list. Preserve names, identifiers used by code, and source references as needed. Translate visible UI and report copy consistently.
2. Keep underlying numbers and units in the data files. Format numbers, percentages, and currencies at the display layer. For an Indonesian deliverable, use comma decimals and include the currency explicitly when values are in USD.
3. Translate periods, category names, and benchmark qualifiers consistently. Preserve the cohort and comparison level in the translated label.
4. Inspect strings in the rendered page, deck, or sheet. Check wrapping, clipping, numeric formatting, and consistent date ranges. Recheck headings, legends, status messages, and download labels.
